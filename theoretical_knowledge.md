# Theoretical Knowledge

## SOC Fundamentals
- Definition of a Security Operations Center (SOC)
- Roles: Tier 1 (alert triage), Tier 2 (incident analysis), Tier 3 (threat hunting)
- Key responsibilities: detection, response, escalation, evidence preservation

## Core Concepts
- **Threat Intelligence:** Indicators of Compromise (IOCs), TTPs (Tactics, Techniques, Procedures)
- **Incident Response Lifecycle:** Preparation → Detection → Containment → Eradication → Recovery → Lessons Learned
- **Log Analysis:** Syslog, auditd, Wazuh rules, Elastic dashboards
- **Forensics:** Hashing, chain of custody, evidence integrity

## Tools Overview
- Wazuh for monitoring
- Elastic Security for visualization
- TheHive for case management
- CrowdSec for automated blocking
- Velociraptor for forensic collection# Theoretical Knowledge
