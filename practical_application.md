# Practical Application

## Lab Setup
- Kali Linux VM with SOC tools installed
- Simulated vulnerable Samba service for exploitation
- Attack simulation using Metasploit

## Exercises
1. **Detection:** Trigger exploit and observe Wazuh alerts
2. **Response:** Configure CrowdSec to block attacker IP
3. **Escalation:** Document incident in TheHive
4. **Evidence Preservation:** Collect forensic artifacts with Velociraptor

## Outcomes
- Alerts successfully detected and triaged
- IP blocking automated
- Incident escalated with structured workflow
- Evidence preserved with integrity checks
